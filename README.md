# Project/Time Manager
## Desktop application for managing your projects and scheduling your day! (requires installation of Java to run)

### Project Management:
* Create a project with an estimated completion time and start date (with an optional deadline)
* Divide your project up into tasks that can be marked complete as you go

Time Management:
* Plan your day out ahead
* Enter everything you want to do and when, and have it all viewable at once

## Install by downloading the .jar file on this GitHub page. Then, simply run it!
